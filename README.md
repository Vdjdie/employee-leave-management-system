# Employee Leave Management System

## About
The Employee Leave Management System is a web-based application developed to manage employee leave requests efficiently.

## Technologies Used
- Java
- Spring Boot
- HTML
- CSS
- JavaScript
- MySQL

## Features
- Employee dashboard
- Manager dashboard
- Employee leave request management
- Leave approval and rejection
- User management

## Project Structure
- `src` – Application source code
- `pom.xml` – Maven dependencies and configuration
